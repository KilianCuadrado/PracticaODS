# Objectiu de l’aplicació 
>[!INFO] L'objectiu d'aquest projecte és desenvolupar una aplicació web completa, dinàmica i focalitzada en resoldre un repte relacionat amb els Objectius de Desenvolupament Sostenible (ODS). L'aplicació haurà de conscienciar, gestionar o aportar solucions a una problemàtica ambiental o social mitjançant una plataforma web interactiva. Aquest projecte és de caràcter transversal i implica diversos mòduls del cicle formatiu:

- **Desenvolupament web en entorn client:**  Us encarregareu de la part Front-end (interfície, usabilitat, DOM), el consum de dades de forma asíncrona i la creació  d'una  API  REST  simulada utilitzant l'entorn Node.js i Express.

- **Sostenibilitat aplicada al sistema productiu:** S'avaluaran els vostres  coneixements sobre desenvolupament sostenible, impacte ambiental i economia circular aplicats al vostre projecte tecnològic.

- **Desenvolupament web en entorn servidor:** Aquest mòdul està impartit per altres  docents. Més endavant  ells us donaran les seves pròpies indicacions. De moment, des del mòdul de client construireu els endpoints bàsics (API REST) per tal de fer funcionar la web. Posteriorment, des del mòdul de servidor, s'implementarà l'extracció de dades des d'una Base de Dades real.

## Estat actual d'implementació

- Aplicació web operativa amb navegació completa (10+ pàgines) i contingut ODS 14 + 15.
- API REST simulada amb Node.js/Express sobre `data/db.json`, amb operacions CRUD i fluxos de relacions.
- Comunicació asíncrona implementada al front-end amb `fetch` i `async/await`.
- Fluxos per rols actius: `guest`, `user`, `org`, `admin`.
